# gemma-4-dev-agent

Agent and tooling for the Kaggle *Gemma 4 Developer Agent* competition.

- `submission/` - the agent (agent.yaml, prompt, sampling and budget configs)
- `validate_submission.py` - checks and compiles the submission with the official harness
- `build_notebook.py` - generates the Kaggle notebook in `kaggle/`
- `download-data.ps1`, `load-env.ps1` - data download and credential helpers
